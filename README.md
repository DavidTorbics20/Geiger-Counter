# Geiger-Counter

This projekt is based on the design, schematics and idea of [Konstantin Kogan](https://www.instagram.com/konsta.kogan/). A large portion of the information was sourced from [this](https://www.instructables.com/DIY-Arduino-Geiger-Counter/) page. Although the innitial idea and principle are a result of Konsta Kogan's work, I intend to expand the project by installing an air quality mesauring unit and furthermore expanding on the codebase, as well as providing the files for the case. This project is first case meant for my own use case but also for those who would like to attemp to recreate it as well.
